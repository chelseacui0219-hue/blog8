# Simulation, Bootstrap Confidence Intervals, and Hypothesis Testing

An interactive Monte Carlo simulation study demonstrating the foundations of statistical inference, built with R and Shiny.

## Overview

This project uses simulation to explain three core concepts in statistics:
1. **Bootstrap Confidence Intervals**: Constructing confidence intervals by resampling from a single observed sample.
2. **Coverage of Confidence Intervals**: Demonstrating the long-run frequentist meaning of "95% confidence" via repeated simulation.
3. **Hypothesis Testing**: Visualizing the null distribution and p-values by simulating data under the null hypothesis.

The goal is to strip away the "magic" of statistical formulas by showing the underlying data-generating processes.
